# ncmn_global_flags

전세계 깃발 등록 현황을 지도 위에서 관리하는 Streamlit 앱입니다.

## 실행

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 로 접속합니다. 세계지도는 Plotly가 CDN에서 지도 데이터를
내려받아 그리므로 브라우저가 인터넷에 연결되어 있어야 합니다.

## 사용법

- **초기 화면**: 한국이 가운데 오는 평면 세계지도가 화면 가득 표시됩니다. 국가 색과 숫자 배지는
  등록된 깃발 수이고, 지도 아래에 국가별 합계 표가 있습니다.
- **국가 선택**: 지도에서 국가를 클릭하거나, 작은 국가는 오른쪽 위 검색 상자에서 선택합니다.
- **관리자 모드** (오른쪽 위 `사용자 모드` 버튼 → 비밀번호 입력): 국가별 확대 이미지 업로드,
  필요 깃발 수, 시도 목록을 설정하고 등록 정보를 삭제하거나 CSV로 내려받습니다.
- **사용자 모드**: 국가 확대 이미지에서 위치를 클릭한 뒤 시도, 현재 깃발 수, 도시명, 주소, 기관명,
  현지 연락자명, 연락처, 이메일주소, 등록자명, 등록 이미지를 입력해 등록합니다.
  국가 화면에는 시도별 깃발 수 합계 표가 표시됩니다.

## 설정

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `NCMN_ADMIN_PASSWORD` | `admin` | 관리자 모드 비밀번호. 운영 시 반드시 변경하세요. |
| `NCMN_DATA_DIR` | `./data` | SQLite DB(`flags.db`)와 업로드 이미지 저장 위치 |

지도 중심 경도는 `app.py`의 `MAP_CENTER_LON`(기본 150°E)으로 조정합니다.
